## Core Features

- **Repository Integration**: Connect and analyze GitHub repositories with token-based authentication
- **AI-Powered Querying**: Ask questions about codebases using multiple AI providers (Google Gemini, Ollama/Llama)
- **Code Embeddings**: Generate and store vector embeddings of source code for semantic search
- **Project Management**: Multi-user project collaboration with role-based access
- **Commit Tracking**: Monitor and analyze repository commits with detailed metadata
- **Authentication**: Secure user authentication with NextAuth.js

## Target Users

Developers, code reviewers, and teams who need to quickly understand, analyze, and query large codebases without manually browsing through files.

## Key Value Proposition

Transform static code repositories into interactive, queryable knowledge bases using AI to provide instant insights about code structure, functionality, and changes.
